# TimeRAF — repository map & handoff guide

TimeRAF is a research extension built **on top of a fork of
[Time-Series-Library (TSLib)](https://github.com/thuml/Time-Series-Library)**.
That is the single most useful fact for orienting yourself: roughly half the
root directory is inherited upstream boilerplate, and the TimeRAF contribution
lives in a handful of clearly-named places.

## Read these first, in this order

1. `README_ts_rag.md` — what TimeRAF is and what each `ts_rag/` module does.
2. `docs/publication_results/README.md` — the accepted experimental results.
3. `paper/README.md` — how to build the manuscript and regenerate figures/tables.
4. `docs/research_protocol.md` and `docs/research_log.md` — frozen protocols and
   the decision trail (the log is long; skim by date).

`README.md` / `README_zh.md` are the **upstream TSLib** READMEs, kept unchanged.
They describe the base library, not TimeRAF.

## Directory map

### TimeRAF contribution

| Path | What it is |
|---|---|
| `ts_rag/` | The method. Retrieval, residual correction, online ensembling, significance testing, and the frozen publication/appendix gates. See `README_ts_rag.md`. |
| `scripts/*.py` (62 files) | Experiment drivers, orchestration, summarizers, and auditors. Grouped by prefix: `run_*` launch work, `summarize_*`/`aggregate_*` derive results, `audit_*` are acceptance gates, `build_*`/`index_*` produce manifests and catalogs, `fetch_*`/`prepare_*`/`submit_*`/`greenland_*` drive remote cluster runs, `timefuse_*` are the long-running pipeline controllers. |
| `scripts/*.sh` | Detached worker/monitor controllers for those pipelines. |
| `docs/` | Versioned research record: frozen protocols (`*_protocol.json`), experiment manifests (`*.jsonl`), checkpoint catalogs, and the research log. |
| `docs/publication_results/` | **The compact, authoritative result snapshot.** Start at its `README.md`; `key_metrics.json` has machine-readable headline values. `sha256sum -c SHA256SUMS` verifies all 34 files. |
| `tests/` | pytest suite for the TimeRAF modules and pipelines. |
| `paper/` | ICLR manuscript (LaTeX), figure/table generators, and their input data. |
| `requirements-research.txt` | Deps for the main research environment. |
| `requirements-appendix.txt` / `.lock` | Pinned deps for the AutoGluon/Chronos appendix baselines (deliberately a separate venv). |
| `requirements-greenland.txt`, `Dockerfile.greenland` | Remote large-scale cluster runtime. |

### Inherited from upstream TSLib (largely unmodified)

| Path | What it is |
|---|---|
| `run.py` | Upstream training/eval entry point. TimeRAF wraps it via `ts_rag/exp_wrapper.py`. |
| `models/` | 42 baseline forecasting models (TimeMixer, PatchTST, iTransformer, …). |
| `layers/`, `utils/`, `exp/`, `data_provider/` | Upstream building blocks: layers, metrics/tools, experiment loops, dataset loaders. |
| `scripts/<task>/` | Upstream shell scripts per task (`long_term_forecast/`, `short_term_forecast/`, `classification/`, `imputation/`, `anomaly_detection/`, `exogenous_forecast/`). |
| `tutorial/`, `pic/` | Upstream tutorial notebook and README images. |
| `README.md`, `README_zh.md`, `CONTRIBUTING.md`, `LICENSE`, `Dockerfile`, `docker-compose.yml` | Upstream docs and container setup. |

## What is NOT in this repository

Everything below is `.gitignore`d, so a fresh clone will not have it. None of it
is needed to read the code, the results, or the paper — but you need the first
two items to actually re-run experiments.

| Missing | How to get it |
|---|---|
| `dataset/` (391M) | Download the preprocessed TSLib datasets from [Google Drive](https://drive.google.com/drive/folders/13Cg1KYOlzM5C7K8gK8NfC-F3EYxkM3D2?usp=sharing), [Baidu Drive](https://pan.baidu.com/s/1r3KhGd0Q9PJIUZdfEYoymg?pwd=i9iy), or [Hugging Face](https://huggingface.co/datasets/thuml/Time-Series-Library), and unpack into `./dataset`. |
| `checkpoints/` | Trained weights. Ask the previous owner to transfer these directly; the full 208-checkpoint replay catalog is ~17.5 GB and lives on the original compute cluster, not in Git. |
| `ts_rag_outputs/` | Experiment output tree. Regenerated by the `scripts/run_*` drivers. Raw per-run prediction dumps are ~10 GB and were deliberately not shared. |
| `.venv/` | See "Getting a working environment" below. |
| `paper/reference/` | Downloaded related-work PDFs and a copy of the ICLR style files. Not needed: `paper/latex/` already carries `iclr2027_conference.sty`, `.bst`, `natbib.sty`, `fancyhdr.sty` and all 7 figure PDFs, so the manuscript builds standalone. |
| `paper/tools/tectonic` | The LaTeX engine binary. Download [Tectonic](https://tectonic-typesetting.github.io/) 0.15.0 and drop it at `paper/tools/tectonic`, or use any local TeX installation with `paper/latex/Makefile`. |
| `paper/latex/main.pdf`, `paper/.cache/`, `paper/.tmp/` | Build outputs, LaTeX package cache, and figure iteration drafts. All regenerable. |

## Getting a working environment

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements-research.txt
python -m pytest tests -q
```

The AutoGluon/Chronos appendix baselines need their own pinned environment,
built from `requirements-appendix.lock` via
`scripts/provision_appendix_environment.py`. Do not install them into the same
venv — the Torch versions conflict on purpose.

## Redacted infrastructure identifiers

This project's large-scale experiments ran on a private internal cluster. Every
concrete resource identifier has been replaced with an angle-bracket
placeholder throughout the tree. If you see one of these, it is a redaction, not
a bug or a missing config value:

| Placeholder | Was |
|---|---|
| `<AWS_ACCOUNT_ID>`, `<AWS_ACCOUNT_ID_DEV>`, `<AWS_ACCOUNT_ID_LOGS>`, `<AWS_ACCOUNT_ID_IMAGES>` | AWS account numbers |
| `<ECR_REGISTRY>` | Container registry host |
| `<GREENLAND_ENDPOINT>` | Internal scheduler API endpoint |
| `<SAGEMAKER_DOMAIN_ID>`, `<DEV_SPACE>`, `<P5_SPACE>`, `<LEGACY_SPACE>` | SageMaker Studio domain and space names |
| `<DEV_BUCKET>` | S3 bucket for artifacts |
| `<GREENLAND_SERVICE_ROLE>`, `<GREENLAND_CONSOLE_ROLE>`, `<ADMIN_ROLE>` | IAM role names |
| `<STUDIO_LIFECYCLE_CONFIG>` | Studio lifecycle config name |

Consequence: the remote-execution paths — `scripts/greenland_*`,
`scripts/sagemaker_*`, `scripts/timefuse_*worker*.sh`, and their tests — will
not run as-is. Read them as a record of how the reported experiments were
scheduled, and substitute your own infrastructure. Everything that operates on
local files (the method in `ts_rag/`, the summarizers, the auditors, the paper
tooling) works unchanged.

The internal operating-rules file `AGENTS.md` (and the `CLAUDE.md` that included
it) was removed rather than redacted; this document replaces it.

## Two things that will surprise you

- **Result lookups must use `docs/publication_results/a100_composed_summary.json`**
  as the primary matrix (562/585 strict improvements). The A10G summary beside
  it is secondary cross-hardware evidence only — do not average the two or
  silently substitute one for the other. The final audit reports
  `publication_ready=true`, but the strict cross-hardware numerical-consistency
  gate is `false`; both facts are intentional and should be preserved.
- **Non-finite values are treated as failures, not results.** A cell is
  `completed` only when every reported metric is finite.
  `docs/timefuse_numerical_recovery_protocol.json` is frozen and governs how the
  nine affected cells were re-run. Do not re-tune it from observed outcomes.

## Publishing to a private repo

The shareable snapshot lives in a **sibling directory**,
`../TimeRAF-share/`, so the working repo is never disturbed. It is a fresh
`main` branch with a single commit and no upstream fork history — 671 files,
**6.5 MiB packed**. Building it this way was necessary because `.gitignore`
cannot un-track files that are already committed, and the identifiers above
appear throughout the original ~226-commit history.

It is staged but **not committed and not pushed**. To finish:

```bash
cd ../TimeRAF-share
git config user.email "<your-personal-email>"     # keep it repo-local
git commit -m "TimeRAF: research code, results snapshot, and ICLR manuscript"

gh repo create TimeRAF --private --source=. --remote=origin
git remote set-url origin github-personal:ZhiningLiu1998/TimeRAF.git
git push -u origin main
gh repo invite ...                                # or add the collaborator in the web UI
```

Before pushing, re-run the redaction check:

```bash
grep -rInE 'arn:[a-z-]*aws[^ ]*:[0-9]{12}|[0-9]{12}\.dkr\.ecr|IibsAdminAccess' \
  . --exclude-dir=.git
```

It should print nothing. (A bare `[0-9]{12}` search is not useful here — it
matches zero-padded metric values throughout the result JSONs.)
