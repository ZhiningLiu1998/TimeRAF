# TimeRaf ICLR 2027 Draft

This directory contains the anonymous ICLR 2027 manuscript, its outline,
literature notes, reference sources, generated figures, tables, and a
paper-local Tectonic binary.

## Select the real retrieval case

The first-page motivation figure and method overview use deterministic
illustrative cases. The appendix residual-retrieval figure uses a real ETTh1
test case. When the ignored experiment artifacts are available, regenerate the
compact, versionable case file from `paper/`:

```bash
python3 tools/select_real_retrieval_case.py
```

This writes `data/real_retrieval_case.json`, including source hashes,
screening scores, retrieved neighbors, and the exact prediction-reconstruction
check. Figure generation uses this compact file and does not require the large
raw bundles.

## Generate figures

From `paper/`:

```bash
python3 tools/generate_figures.py
```

The script deterministically writes:

- `latex/figures/intro_motivation.pdf`
- `latex/figures/intro_motivation_stadium.pdf` (preserved earlier version)
- `latex/figures/method_overview.pdf`
- `latex/figures/residual_retrieval_example.pdf`
- `latex/figures/ett_gains.pdf`

## Build the manuscript

Install Tectonic 0.15.0, then build from `paper/latex/`:

```bash
make
```

The Makefile uses the paper-local `tools/tectonic` binary when present;
otherwise it uses `tectonic` from `PATH`. Override either choice with
`TECTONIC_BIN=/path/to/tectonic make`.

The final manuscript is `latex/main.pdf`. Tectonic logs and intermediate
files remain under `latex/build/`; the final PDF is moved out of that
directory after a successful build.

## Generate result tables

The primary 585-cell tables are generated by `tools/generate_main_tables.py`.
The additional ensemble, AutoML, and foundation-model tables are generated by
`tools/generate_strong_system_tables.py`. Both scripts validate their source
summaries before writing LaTeX.

From the repository root, regenerate the full-horizon retrieval tables with:

```bash
SOURCE_REVISION="$(jq -r .source_revision \
  docs/publication_results/retrieval_baseline_summary.json)"
LAUNCHER_REVISION="$(jq -r .launcher_revision \
  docs/publication_results/retrieval_baseline_summary.json)"
PROTOCOL_SHA256="$(sha256sum docs/retrieval_baseline_protocol.json |
  cut -d' ' -f1)"
CATALOG_SHA256="$(jq -r .catalog_sha256 \
  docs/publication_results/retrieval_baseline_summary.json)"
PYTHONPATH=. python3 paper/tools/generate_retrieval_baseline_tables.py \
  --input docs/publication_results/retrieval_baseline_summary.json \
  --native-input \
    docs/publication_results/native_retrieval/native-52-schema-v2.json \
  --run-metadata \
    docs/publication_results/retrieval_baseline_run_metadata.json \
  --startup-topology \
    docs/publication_results/retrieval_baseline_startup_topology.json \
  --completion-receipt \
    docs/publication_results/retrieval_baseline_completion_receipt.json \
  --expected-source-revision "$SOURCE_REVISION" \
  --expected-launcher-revision "$LAUNCHER_REVISION" \
  --expected-protocol-sha256 "$PROTOCOL_SHA256" \
  --expected-catalog-sha256 "$CATALOG_SHA256"
```

The retrieval generator requires exact 585-cell coverage, complete metric and
delta consistency, eight distinct P5 worker bindings, and hashes that match
the full-horizon completion receipt. The superseded 208-cell snapshot cannot
pass these checks.
