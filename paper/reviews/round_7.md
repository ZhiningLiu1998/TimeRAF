## Adjudication

1. **Accepted:** the residual strip extended under the historical context
   although it represents only the forecast horizon. It now begins at the
   forecast origin and uses exactly the future width.
2. **Accepted:** the residual reference line was not located at zero. Its
   vertical position is now computed from the plotted residual range.
3. **Partly accepted:** several annotations were too small at manuscript
   scale. Critical labels were enlarged and shortened; the two-path layout was
   retained because it remains readable on the compiled page.
4. **Accepted:** the original numbers did not support the label that routine
   traffic dominated distance. The ordinary-evening analog now differs across
   the routine window, the cue contributes less squared distance, and runtime
   checks enforce both that fact and the intended nearest-neighbor ordering.
5. **Accepted:** blue represented both the base forecast and the query context.
   Query contexts are now consistently black.
6. **Rejected:** red need not mean failure alone. In this figure it marks
   event/error-related material: the pickup cue, retrieved analog, and stored
   residual. Failure and success remain independently encoded by the cross,
   check, band color, and path position.
7. **Accepted:** the direct path said `copy` while applying a level shift. It
   now performs and labels a raw analog copy, and the introduction describes
   the depicted level-and-continuation mismatch.
8. **Accepted:** separate automatic scales hid the different traffic levels.
   The historical event and corrected query now share one vertical range and
   equal plot heights.
9. **Accepted:** `same missed surge` could imply retrieval by the unknown
   future. The historical key is now described and highlighted as a matching
   pickup buildup at a different level.
10. **Accepted:** the add arrow appeared to originate from the historical
    window. It now starts at the residual strip, which is labeled
    `residual = truth - base`, and terminates at the query-base output.
11. **Rejected:** a six-item legend would duplicate direct labels and crowd
    the first-page figure. Truth and base retain the only shared line legend;
    retrieved, residual, and corrected content are labeled at their operations.
12. **Partly accepted:** the divider needed to identify both the forecast
    origin and the event time. Panel (a) now says `origin: event ends`; repeating
    the same text in every small window would add clutter without new meaning.
13. **Accepted:** the two residual-memory windows used different heights and
    scales. They now use equal geometry and one shared range.
14. **Accepted:** `routine evening learned` overstated what the anchored base
    showed. The label now says `routine decline forecast`.
15. **Accepted:** the corrected forecast reused the truth array. It is now
    explicitly computed as `base + residual`, checked against truth, and drawn
    as a dashed green overlay so the black truth remains visible.
16. **Accepted:** `reveals` overstated what an illustrative construction can
    establish. The text now says `illustrates`, and the canvas labels the
    scenario as illustrative.
17. **Rejected:** the non-floating caption block is deliberate. It fixes the
    motivation figure on the first page; changing to a standard float would
    alter that layout contract without improving the scientific content.
18. **Accepted:** context and forecast used inconsistent horizontal step
    scales. The split is now `17 / 29`, matching 17 observed intervals and 12
    forecast intervals.
