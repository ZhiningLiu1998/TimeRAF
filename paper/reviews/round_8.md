# Figure 1 Iconography Debate

- Reviewer: Claude Opus through ASBX Claude Code 2.1.246.731
- Scope: Figure 1 standalone and at manuscript scale
- Constraint: preserve the scientific story and data; add restrained visual
  identifiers without turning the figure into a product UI
- Process: two explicit claim-response rounds followed by local adjudication

## Round 1

Claude argued that the first icon draft should be removed because:

1. the filled stadium badge resembled a home icon;
2. the filled memory badge resembled a hamburger menu;
3. the event flag collided with the subtitle and duplicated the origin line;
4. the saturated search badge overloaded the red channel;
5. filled circles competed with the cross/check verdict circles; and
6. badge, title, subtitle, and plot edges were not aligned.

These concrete findings were accepted. The broader recommendation to remove
all iconography was rejected because it would discard the requested visual
semantics rather than repair them. The second draft replaced filled circles
with three unframed outline marks: a top-view venue/field, a magnifier, and
stacked memory records containing a residual trace. The event flag was
removed, the text origin marker was restored, and header geometry was aligned.

## Round 2

Claude accepted that the filled-circle and flag problems were resolved and
withdrew the recommendation to remove all icons. It then proposed:

1. removing the stadium mark because its interior detail did not survive
   manuscript reduction;
2. retaining the magnifier unchanged;
3. moving the memory mark down, strengthening the back record, and increasing
   its layer offset;
4. aligning the magnifier's left edge with the panel; and
5. increasing the subtitle-to-origin spacing.

Items 2--5 were accepted and implemented. Item 1 was partly accepted: the
small diagonal details were removed, but the stadium mark itself was retained
because the user explicitly requested domain iconography and the adjacent
`stadium district` label disambiguates it. The final mark contains only a
venue outline, playing field, and center line.

## Final Decision

The final figure keeps all three requested semantic marks in one restrained
outline style. None is enclosed in a decorative badge, none enters a data
plot, and the existing cross/check remain the only verdict symbols. The
stadium mark grounds the example; the magnifier and layered records distinguish
the two retrieval mechanisms.
